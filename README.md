# ประเมินราคางานพิมพ์ (React + Tailwind CSS)

WebApp สำหรับประเมินราคางานพิมพ์ ระบบจะถามรายละเอียดงานทีละข้อ แสดงตัวอย่างงานแบบ 2D/3D และคำนวณราคาให้ทันที ใช้ได้บนมือถือ แท็บเล็ต และเดสก์ท็อป

```bash
npm install
npm run dev      # เปิดที่ http://localhost:5173
npm run build    # ได้ไฟล์พร้อมใช้งานในโฟลเดอร์ dist/
```

Stack: React 19, Vite 7, Tailwind CSS 4 (`@tailwindcss/vite`)

## โครงสร้าง

```
src/
  data/catalog.js          ประเภทงาน 14 แบบ คำถาม ตัวเลือก และอัตราราคา  ← แก้ราคาที่นี่
  lib/pricing.js           สูตรคำนวณราคา (ค่าเพลท กระดาษ พิมพ์ ตกแต่ง VAT ระยะเวลาผลิต)
  lib/preview.js           สร้างข้อมูลสำหรับวาดตัวอย่าง 3D และแบบกาง 2D จากคำตอบ
  hooks/useEstimator.js    เก็บสถานะของขั้นตอนถาม–ตอบ
  hooks/useElementSize.js  วัดขนาดพื้นที่แสดงตัวอย่าง (ResizeObserver)
  components/
    Header.jsx  TypePicker.jsx  ChatPanel.jsx  PreviewStage.jsx  PriceSummary.jsx
  index.css                ค่าสีและฟอนต์ (Tailwind @theme)
```

## เลย์เอาต์ตามขนาดหน้าจอ

| หน้าจอ | Breakpoint | เลย์เอาต์ |
|---|---|---|
| มือถือ | < 768px | ตัวอย่างอยู่บน แชตอยู่ล่าง แถบราคาติดด้านล่าง (แตะเพื่อดูรายละเอียด) |
| แท็บเล็ต | `md` ≥ 768px | ตัวอย่าง + การ์ดราคาอยู่แถวบน แชตเต็มความกว้างด้านล่าง |
| เดสก์ท็อป | `xl` ≥ 1280px | 3 คอลัมน์: แชต \| ตัวอย่าง \| ราคา |

## การปรับราคา

อัตราราคาใน `catalog.js` ทั้งหมดเป็น**ค่าตัวอย่าง** ต้องเปลี่ยนเป็นราคาจริงก่อนนำไปใช้

- `base` = ราคาต่อชิ้นอ้างอิง (ที่ 1,000 ชิ้น) และ `setup` = ค่าเพลท/แม่พิมพ์ตั้งต้น
- ตัวคูณ: `sf` ขนาด, `mf` วัสดุ, `cf` สีพิมพ์, `csf` ค่าเพลทตามจำนวนสี, `pf` จำนวนหน้า, `f` ตัวคูณทั่วไป
- ค่าบวกเพิ่ม: `add` บาท/ชิ้น, `addS` บาท/ชิ้น (ปรับตามขนาด), `setup` ค่าตั้งเครื่องเพิ่ม, `days` จำนวนวันผลิตที่เพิ่มขึ้น
- ส่วนลดตามจำนวน: `Math.pow(1000 / qty, 0.18)` ใน `lib/pricing.js`

ปุ่ม "ขอใบเสนอราคา" ตอนนี้แค่แสดงข้อความยืนยันเท่านั้น ถ้าจะส่งข้อมูลไปที่ API ให้ต่อที่ `requestQuote` ใน `hooks/useEstimator.js` โดยส่ง `type`, `answers` และ `price` ไปด้วย
"# print-price-estimator-sample"
